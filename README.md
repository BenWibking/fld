# 3-D FLD benchmarks

Build both test problems:

```sh
git submodule update --init
gmake -j8
```

## Penrose-sphere AMR Clouds

```sh
mpirun -np 2 ./main3d.gnu.MPI.ex cloud_fine_n=64 cloud_case=amr \
  cloud_write_plotfile=0 cloud_iteration_output=0
```

`cloud_case=uniform` runs the same fine resolution without AMR, and
`cloud_case=both` runs both in one invocation. `cloud_fine_n` must be a
multiple of 32 for AMR. The 74 sphere centroids are fixed in
`PenroseCloudCenters.H`, generated by `scripts/penrose_cloud_relax.py` from a
relaxed Penrose vertex patch. See
`benchmarks/penrose-cloud-relaxation/RESULTS.md` for geometry and run results.

`cloud_predictor_steps` limits the damped predictor solves before Newton-Krylov
(default 20). Set it to `0` to skip predictors; negative counts are rejected.
Set `cloud_flux_limiter=0` for the linear diffusion problem.

For the scaling benchmark, rebuild the preconditioning matrix and AMG
hierarchy at every Newton step, including when the limiter is disabled.
This deliberately emulates a nonlinear solve whose operator changes each
Newton step. Do not reuse the matrix or hierarchy across Newton steps or
replace this benchmark's Newton workflow with a single linear solve.
Krylov matrix-vector actions remain matrix-free; matrix assembly is for
preconditioning. See `scaling/README.md` for the benchmark configuration.

For native AMG setup message counts, add
`mlabeclap_amg.measure_setup_messages=1`. Each setup prints rank-summed
point-to-point send calls and payload bytes by AMG level and phase, plus the
sum of logical collective calls across ranks. The counts exclude messages
generated inside MPI collectives and the reduction used to print the report.

## ICASE 2001-12 radiation diffusion

The ICASE test extends the coupled equations, coefficients, and boundary data
from Section 4 of `papers/icase-2001-12.pdf` to the unit cube. The high-opacity
rectangular prism spans the middle third of x and y and the middle two-thirds
of z. Radiation enters through the x-low Robin face and leaves through the
x-high Robin face; the y and z faces are insulated. The solver uses
cell-centered finite volumes and a block nonlinear iteration.

The default resolution is 24 cells per side. `icase_n_cell` must be divisible
by 6 to align the material interfaces with cell faces. The defaults
`icase_steps=1000` and `icase_dt=0.01` use the paper's time interval. For a
short run:

```sh
mpirun -np 2 ./main3d.gnu.MPI.ex icase_only=1 icase_n_cell=24 \
  icase_steps=2 icase_iteration_output=0 icase_write_plotfile=0
```
