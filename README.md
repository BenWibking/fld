# 3-D FLD benchmarks

Build both test problems:

```sh
git submodule update --init
gmake -j8
```

## Penrose-sphere AMR Clouds

```sh
mpirun -np 2 ./main3d.gnu.MPI.ex cloud_fine_n=64 cloud_case=amr \
  cloud_write_plotfile=0 cloud_iteration_output=0
```

`cloud_case=uniform` runs the same fine resolution without AMR, and
`cloud_case=both` runs both in one invocation. `cloud_fine_n` must be a
multiple of 32 for AMR. The 74 sphere centroids are fixed in
`PenroseCloudCenters.H`, generated by `scripts/penrose_cloud_relax.py` from a
relaxed Penrose vertex patch. See
`benchmarks/penrose-cloud-relaxation/RESULTS.md` for geometry and run results.

`cloud_predictor_steps` limits the damped predictor solves before Newton-Krylov
(default 20). Set it to `0` to skip predictors; negative counts are rejected.
Set `cloud_flux_limiter=0` for the linear diffusion problem.

For the scaling benchmark, rebuild the preconditioning matrix and AMG
hierarchy at every Newton step, including when the limiter is disabled.
This deliberately emulates a nonlinear solve whose operator changes each
Newton step. Do not reuse the matrix or hierarchy across Newton steps or
replace this benchmark's Newton workflow with a single linear solve.
Krylov matrix-vector actions remain matrix-free; matrix assembly is for
preconditioning. See `scaling/README.md` for the benchmark configuration.

For native AMG setup message counts, add
`mlabeclap_amg.measure_setup_messages=1`. Each setup prints rank-summed
point-to-point send calls and payload bytes by AMG level and phase, plus the
sum of logical collective calls across ranks. The counts exclude messages
generated inside MPI collectives and the reduction used to print the report.

`mlabeclap_amg.cf_stencil` selects the coarse/fine flux discretization for
both the matrix-free residual and the assembled preconditioner. The default,
`hypre`, follows `amrex::HypreMLABecLap`: each fine-face flux uses a ghost
value interpolated from the coarse cell, its transverse neighbors, and two
fine cells, and the coarse cell receives the sum of the fine-face fluxes. It
is second-order accurate but gives a nonsymmetric matrix. `two_point` couples
each fine cell to its coarse neighbor with a symmetric two-point flux, which
is inconsistent at the interface and only first-order accurate. Run
`mms_only=1 mms.n_cells=16 32 64` for a manufactured-solution convergence
study of either stencil; see `benchmarks/2026-10-27-cf-stencil/RESULTS.md`.

## ICASE 2001-12 radiation diffusion

The ICASE test extends the coupled equations, coefficients, and boundary data
from Section 4 of `papers/icase-2001-12.pdf` to the unit cube. The high-opacity
rectangular prism spans the middle third of x and y and the middle two-thirds
of z. Radiation enters through the x-low Robin face and leaves through the
x-high Robin face; the y and z faces are insulated. The solver uses
cell-centered finite volumes. Unlike the paper, the material equation has no
heat conduction, so it is local to each cell.

The default resolution is 24 cells per side. `icase_n_cell` must be divisible
by 6 to align the material interfaces with cell faces. The defaults
`icase_steps=1000` and `icase_dt=0.01` use the paper's time interval. For a
short run:

```sh
mpirun -np 2 ./main3d.gnu.MPI.ex icase_only=1 icase_n_cell=24 \
  icase_steps=2 icase_iteration_output=0 icase_write_plotfile=0
```

`icase_solver` selects the nonlinear solver. `ne_newton_krylov` (default) and
`ne_quasi_newton` use nonlinear elimination (Brunner, Haut & Nowak 2020,
`papers/`): T is solved cell by cell for the current E, leaving a system in E
alone. `ne_newton_krylov` applies Jacobian-free Newton-Krylov to that reduced
system; `ne_quasi_newton` is the paper's Algorithm 2 with frozen
coefficients. `newton_krylov` is Jacobian-free Newton-Krylov on the coupled
(E, T) system, with the material eliminated linearly (Schur complement) in
its preconditioner. For both Newton-Krylov solvers, Newton starts from the
previous step; if it fails, the step is retried from up to 20 damped
linearized (Picard) predictor iterations. The default problem never needs
this fallback; finer grids or larger time steps (e.g. `icase_n_cell=48`,
`icase_dt=0.1`) do. The coupled solver matches `ne_newton_krylov` on the
default problem. See
`benchmarks/2026-10-27-linear-vs-nonlinear-elimination/RESULTS.md` and
`benchmarks/2026-10-27-nonlinear-elimination/RESULTS.md`.

## Moving medium to O(v/c)

`vc_only=1` runs grey flux-limited diffusion coupled to the material energy
in a medium with a prescribed uniform velocity `vc.velocity` (in units of c),
on the periodic unit cube, to first order in v/c. The matter-radiation
four-force is the mixed-frame form of He, Wibking & Krumholz (2024,
`papers/stae1244.pdf`), Eqs. (3)-(4). The radiation flux includes the
enthalpy advection v.(E I + P) with the Levermore Eddington tensor of the
limiter; the material receives c G0 - v.G, so E + T loses the work done by
the radiation force on the flow. Material advection is explicit and operator
split before the implicit update. Opacity is `vc.sigma0 * T^-vc.opacity_power`.

`vc.solver` selects `newton_krylov` (default; coupled, with a
Schur-complement preconditioner) or `ne_lagged` (nonlinear elimination with
the work term lagged over an outer iteration). `vc.test=pulse` advects an
equilibrium temperature pulse;
`vc.test=mms` runs a steady manufactured solution (requires `vc.limiter=0`;
`vc.advection=centered` gives second order, `upwind` first order):

```sh
mpirun -np 4 ./main3d.gnu.MPI.ex vc_only=1 vc.test=pulse vc.solver=ne_lagged
```

The defaults are optically thick (`vc.sigma0=1000`, `vc.opacity_power=3`).
As for ICASE, if Newton fails the step is retried from up to 20 damped
frozen-coefficient (Picard) predictor iterations; optically thin,
limiter-dominated cases need this. Material advection is explicit, so
`vc.dt` must satisfy dt * sum |v_d|/dx_d <= 1.

See `benchmarks/2026-10-27-moving-medium/RESULTS.md`.
